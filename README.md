## Deskripsi
Program ini dirancang untuk membaca data nilai matematika, memvalidasi nilai, menghitung statistik kelas, menentukan ketuntasan berdasarkan KKM, dan menyimpan laporan.

## Struktur Proyek
- `proposal.md`: rancangan proyek.
- `data/nilai_contoh.txt`: data nilai contoh.
- `src/main.py`: program utama.
- `src/data_io.py`: membaca data dan menyimpan laporan.
- `src/analisis.py`: menghitung statistik dan ketuntasan.
- `src/utilitas.py`: memformat laporan.
- `tests/test_case.md`: daftar pengujian.
- `output/.gitkeep`: menjaga folder output tetap ada di GitHub.

## Cara Menjalankan
Jalankan perintah berikut dari folder utama proyek:

```bash
python src/main.py
```

Hasil laporan akan disimpan di folder `output`.
